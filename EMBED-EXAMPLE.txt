STRICT STYLE ISOLATION (OPTIONAL)

1. Upload the complete folder to your own hosting, for example /dovocci-landing/.
2. Add this HTML to the parent page and replace the URL with your real hosted URL:

<iframe
  src="https://YOUR-DOMAIN/dovocci-landing/index.html"
  title="Dovocci Photography Studio Dubai"
  style="display:block;width:100%;height:100vh;border:0"
  loading="lazy">
</iframe>

An iframe isolates the page from the parent theme's CSS. It has its own vertical scrolling. Automatic iframe height requires JavaScript, so it is intentionally not included in this no-JavaScript edition.

For a standalone landing page, simply serve index.html and do not use an iframe.
